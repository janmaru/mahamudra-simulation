# Is Reality a Simulation?

This repository is a book written as an open investigation:

> Is the reality we live in a computer simulation?

We do not really want an answer. 

In some sense we start our inquiry from the idea that yes, **it is.**
Some might argue that beginning an investigation with such a strong bias is unacceptable or, at the very least, futile from the outset. 
But perhaps that objection is itself part of the investigation.

If we are living in a simulation, then the preceding sentence may be irrelevant by construction: the premises of our inquiry would themselves be artifacts of the simulation. 

Yet it would still matter as an observation about the outcome.

If we are not living in a simulation, on the other hand, the sentence remains consistent with the premises from which we began.

And so we proceed from an intentionally compromised starting point.

We believe the hypothesis must be true, and we want to discover what follows if it is.

The purpose is not to prove that reality is a simulation.

The purpose is to see how far the hypothesis can go.

## How the book is organised

Every Markdown file in `docs/` is a chapter or a sub-chapter. File names are
prefixed with a number so that alphabetical order matches reading order:

| Prefix    | Meaning                                   |
|-----------|-------------------------------------------|
| `NN-`     | Chapter `NN`                              |
| `NN.M-`   | Sub-chapter `M` of chapter `NN`           |
| `00-`     | Front matter (introduction)               |
| `99-`     | Back matter (bibliography)                |

Each chapter follows the same template:

1. **Question under investigation** — one sentence.
2. **Predictions** — what we should observe if the answer is *yes*, what if *no*.
3. **Evidence for** — with sources.
4. **Evidence against** — with sources.
5. **Provisional verdict** — a short, revisable judgement.
6. **Open threads** — what would change the verdict.
7. **Sources** — pointers into `docs/99-bibliography.md`, cited as `[Author Year]`.

Source documents live in `archive/`.

  of it.

## Conventions

- Language: English.
- Citations: `[Author Year]` inline, resolved in `docs/99-bibliography.md`.
- Every factual claim about physics, computation or philosophy must point to a
  source or be flagged explicitly as speculation.
- Verdicts are written in the present tense and dated when they change.
